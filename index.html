Your photos. Your network.
Nobody else's.

A privacy-first digital photo frame for Android. It plays photos from a folder you choose — on the device, on your NAS, or over WebDAV — over your local network only. No account, no cloud upload, no ads.

View on GitHub Build from source

This is pre-release software. The codebase and test suite are substantial and actively reviewed, but hardware soak testing and a signed release build have not been completed. See KNOWN_LIMITATIONS.md for exactly what is and isn't validated yet.

What it does

A merged pool of sources, played as one slideshow, with the controls a frame left running for years actually needs.

Multiple sources, one slideshow

Local SAF folder, SMB/CIFS share, Synology File Station, WebDAV/Nextcloud, or bundled samples — mixed into one merged pool.

Folder-balanced shuffle

No-repeat-per-cycle shuffle that balances across folders, or straightforward ordering by date-taken, filename, or folder.

Favourites & hidden photos

Curate right from the slideshow — mark favourites, hide the ones you don't want to see again.

Portrait collages

Two- or three-up portrait layouts, so a portrait photo doesn't play alone with huge letterboxing.

Motion & transitions

Ken Burns pans, crossfades, and a full set of slide transitions.

Overlays & schedules

Clock, date, folder, and weather overlays; quiet hours, brightness timelines, and automatic re-scans.

On-device web panel

Set up and remote-control from a phone or laptop — QR pairing, live status, diagnostics, encrypted backup/restore.

D-pad friendly

Built to work on Android TV boxes with a remote, not just touchscreens.

Privacy, by construction

Not a policy promise — properties enforced by what the app is (and isn't) allowed to do.

  • No broad storage/media permission is ever requested. Local folders are accessed through Android's Storage Access Framework — a scoped grant to the one folder you pick — verified on every build by an automated permission-audit gate.
  • No cloud dependency. NAS/SMB, Synology, and WebDAV credentials and photo bytes never leave your LAN.
  • Secrets live in the Android Keystore, not in a plain settings file.
  • The web control panel is LAN-only by design — see WEB_SECURITY.md for exactly what that does and doesn't protect against.

Building from source

There's no packaged release yet — build the debug APK yourself.

git clone https://github.com/ami3go/FamilyPhotoFrame.git
cd FamilyPhotoFrame
./gradlew testDebugUnitTest   # pure-logic + JVM tests
./gradlew assembleDebug       # debug APK

A release build falls back to debug signing unless you configure a real keystore — see BUILD_NOTES.md. Don't distribute a debug-signed APK.
