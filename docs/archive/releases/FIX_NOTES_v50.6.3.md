# FamilyPhotoFrame v50.6.3 — Playback Web Layout Fix

## Fixed

- Replaced the generic auto-fit Playback card grid that could create four cramped desktop columns.
- Added a deliberate two-column Playback layout with natural card heights.
- Arranged the controls in horizontal pairs: Timing + Playback order, Portrait collage + Transitions.
- Increased the control column width so selects and numeric fields remain inside their cards.
- Added overflow protection for every Playback form control.
- Added a one-column breakpoint at 1199 px before cards become too narrow.
- Added a dedicated small-screen timing layout: step buttons and slider on the first row, numeric interval on the second row.
- Kept the existing Photos layout fix unchanged.
- Added Web UI contract checks for the Playback layout.
