# Historical project evidence

This directory preserves completed implementation notes, phase reviews, release notes,
and historical verification records. These files are retained for traceability but are
not the current source of truth for implementation.

- `releases/` — version-specific feature, fix, build, type-check, and verification notes.
- `phases/` — completed phase reviews and implementation evidence.
- `reviews/` — milestone code reviews and manual acceptance records.

Current operational documentation remains in the repository root and `docs/`.
